# JerseyZone

Página web sencilla para la venta de jerseys de futbol, hecha con HTML, CSS y JavaScript puro, sin frameworks.

## Descripción

Este proyecto muestra una tienda muy básica llamada JerseyZone en la que se venden algunos jerseys populares (FC Barcelona, Real Madrid, PSG, México, etc.).

Características principales:
- Encabezado tipo navbar con el nombre de la página, enlaces a secciones y un pequeño contador de carrito.
- Sección principal ("hero") con un mensaje de bienvenida y botón para ir a los productos.
- Sección de productos con tarjetas de jerseys y sus respectivas imágenes.
- Botón "Agregar al carrito" que aumenta un contador usando JavaScript.
- Sección de contacto con un formulario sencillo pero que todavía no envía nada (nombre, correo y mensaje).

El diseño es simple, como ejercicio de práctica.
